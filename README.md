# userscript

## YouTube Auto Landscape（実験版）

[`youtube-auto-landscape.user.js`](youtube-auto-landscape.user.js) は、iPhoneのSafariでYouTubeの通常動画を再生中に、端末の横持ちを検知して動画だけを90度回転させます。縦向きロックをオンにしたまま使うことを想定しています。縦に戻すと通常の表示に戻ります。

### Userscriptsへの導入

1. `youtube-auto-landscape.user.js` をダウンロードし、Userscriptsアプリで設定しているスクリプトフォルダに保存します。
2. Safariの拡張機能設定でUserscriptsを有効にし、`www.youtube.com` または `m.youtube.com` へのアクセスを許可します。
3. SafariでYouTubeの通常動画ページ（`/watch?v=...`）を開き、再読み込みします。
4. iPhoneの上部を上にして縦向きに持ち、「↻ 回転を有効化」をタップします。センサーの許可を求められたら許可します。
5. 動画を再生し、iPhoneを左右いずれかに横向きに倒します。

「回転を無効化」をタップすると、動画の表示を戻してセンサーの監視を止めます。再読み込み後には、もう一度有効化してください。YouTube内のページ移動に対応するため、スクリプトはYouTube全体で読み込まれますが、操作ボタンと回転機能は通常動画ページだけで動作します。

### 動作と制約

- CSSによる疑似全画面表示です。iOSの画面回転ロックは変更しません。Safariのアドレスバーなどは残る場合があります。
- 回転中は動画の標準操作を有効にします。動画を一時停止した場合や、通常動画ページから離れた場合、タブを隠した場合には表示を戻します。
- 回転する対象は動画要素です。YouTube独自の操作ボタンや字幕が隠れる場合があります。
- Shorts、埋め込み動画、iOSの標準全画面表示、ピクチャ・イン・ピクチャでは回転しません。OSがすでに横画面にしている場合も回転しません。
- 向きの誤判定を抑えるため、最初に縦持ちでセンサーを合わせ、安定した傾きを250ms検知してから切り替えます。平置きや中間角度では現在の向きを保ちます。
- センサーの値は送信・保存しません。外部ライブラリも読み込みません。
- **iPhone実機での動作は未確認です。** 回転ロック中のセンサー取得やYouTubeの表示との相性は、実機での確認が必要です。YouTubeのページ構造が変わると動作しなくなる可能性があります。

センサーを許可しても情報を取得できない場合は、ボタンの下に案内を表示します。まず、縦持ちで有効化したあとに、再生中の動画が左右の横持ちで回転し、縦持ちで戻るかを確認してください。

参考: [Userscriptsの導入手順とメタデータ](https://github.com/quoid/userscripts)、[Device Orientation and Motion仕様](https://www.w3.org/TR/orientation-event/)。
